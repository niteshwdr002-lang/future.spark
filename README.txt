FUTURE SPARK — Honeycomb Website

FILES
- index.html: page structure and navigation
- style.css: honeycomb theme, responsive layout, animations
- script.js: page content, navigation, Explore More popup and mini activities

RUN
1. Keep all three files in the same folder.
2. Open index.html in a browser, or upload all files to your GitHub repository.
3. For GitHub Pages, go to repository Settings > Pages and choose the branch/folder containing index.html.

NOTES
- The contact page is a front-end demo; it does not send messages to a server.
- The Future Challenge saves text only in the currently open page.
- Google Fonts are loaded online; fallback fonts are included.

CARD INTERACTION FIX
All topic cards now open a details popup when tapped/clicked. The cards can also be opened with Enter/Space on a keyboard.
